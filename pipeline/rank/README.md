# Ранжирование (этап 0.4)

Отвечает на вопрос «чему учить раньше» и проставляет уровни там, где они есть.

```bash
python -m pipeline.rank.build run
python -m pipeline.rank.build top -n 20 --cloze-only --show-cards
python -m pipeline.rank.build stats
python -m pipeline.rank.selftest
```

Таблица `ranking` пересчитывается целиком при каждом запуске: это чистая функция
от содержимого `collocations` и частотного словаря, считается за секунды. После
дозагрузки новых статей порядок пересобирается сам, без миграций.

## CEFR берём только настоящий

Уровни вытаскиваются из тренировочных вопросов, приложенных к статьям: у каждого
стоит `cefr_level`, а в `supported_by.collocations` партнёр назван ровно так же,
как в словаре, — это и позволяет их связать. Привязалось **579 коллокаций из
2605**.

Вывести уровень из частотности мы намеренно не пытаемся. Замер по 1357
размеченным вопросам — медианный zipf правильного ответа:

| A1 | A2 | B1 | B2 | C1 |
|---|---|---|---|---|
| 5.71 | 5.28 | 5.16 | 5.26 | 4.52 |

Между A2 и B2 частотность не различает уровни вовсе. Вычисленный «CEFR» был бы
выдумкой, поэтому где метки нет — там `None`, а для нарезки колод есть отдельная
полоса сложности.

## Порядок изучения

Оценка складывается из трёх вещей: частотности заголовочного слова (вес 2),
частотности партнёра (вес 1) и учебной ценности грамматического отношения.

**Потолок частотности партнёра.** Без него верх очереди занимают предлоги: у них
zipf 6.5–7 против 4–6 у знаменательных слов, и они механически обходят всё
остальное. На первом прогоне 10 из первых 14 карточек оказались предложными
(`can of`, `of know`, `in time`), причём `cans of soup` не несёт никакой учебной
ценности сверх самого слова `can`. Частотность `of` ничего не говорит о
полезности пары, поэтому вклад партнёра обрезан на 5.5.

**Вес отношения.** Подобрать глагол к существительному — тот самый навык, ради
которого всё затевалось, поэтому `verb+obj` получает прибавку, а `prep` — штраф:
зависимый предлог полезен, но это скорее грамматика, чем коллокация.

**Чередование по словам.** Ранжирование само по себе ставит подряд все 30
коллокаций слова `time`, потом все 30 слова `will`. Учить так нельзя — карточки
одного гнезда мешают друг другу вспоминаться. Поэтому очередь раскладывается по
кругу, по одной коллокации от каждого заголовочного слова. После этого первые 12
карточек — 12 разных слов.

## Полосы сложности

Считаются по самой редкой части коллокации.

| полоса | zipf | коллокаций | с пропуском |
|---|---|---|---|
| `core` | ≥ 5.0 | 1377 | 751 |
| `common` | ≥ 4.0 | 832 | 301 |
| `extended` | ≥ 3.0 | 302 | 98 |
| `rare` | < 3.0 | 94 | 36 |

Это не CEFR и называется иначе намеренно — чтобы полосу не путали с уровнем.

## Известные ограничения

* **Повторяющиеся подписи.** У слова `time` три разных кластера дают три записи
  с подписью `in time` и разными примерами. Формально это разные коллокации
  (разные значения), но подряд такие карточки идти не должны — разводить их
  будет очередь дня на этапе 1.
* **Веса подобраны на глаз.** Они разумны и объяснимы, но не выведены из данных
  об обучении. Проверить их можно будет только на собственной статистике
  повторений.
