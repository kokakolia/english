# Пайплайн контента

Пайплайн собирает колоды из словарных статей ozdic. Промежуточные SQLite и
скачанные страницы лежат в `pipeline/data/` и не входят в Git.

## Проверка готового репозитория

Python 3.11+:

```sh
python -m pip install -r pipeline/requirements-check.txt
python -m pipeline.check
```

Проверяются нормализация, ранжирование, карточки, прерывание публикации,
очистка общих файлов и целостность опубликованных колод. Сырьё не требуется.

## Полная сборка

```sh
python -m pip install -r pipeline/requirements.txt
python -m pipeline.sources.ozdic.crawl --help
python -m pipeline.normalize.build run
python -m pipeline.rank.build run
python -m pipeline.deck.build run
```

Для нормализации нужны скачанные статьи и состояние краулера.
Готовая колода в `decks/` позволяет запускать приложение без их получения.

| Модуль                                     | Назначение                                                         |
| ------------------------------------------ | ------------------------------------------------------------------ |
| [`sources/ozdic`](sources/ozdic/README.md) | Скачивание и хранение статей                                       |
| [`normalize`](normalize/README.md)         | Кластеры партнёров, поиск пропуска, постоянные ID                  |
| [`rank`](rank/README.md)                   | Частотность, уровни и порядок изучения                             |
| [`deck`](deck/README.md)                   | Отбраковка, публикация с контрольными суммами, экспорт HTML и Anki |
| [`translate`](translate/README.md)         | Ручные переводы предложений                                        |
| [`usage`](usage/README.md)                 | Ручные пояснения с проверкой контекста                             |
| `sentences`                                | Исправления исходных примеров                                      |

Реестр `schema/card-identities.json` сохраняет ID при изменении состава кластера.
Неоднозначное разделение или слияние останавливает нормализацию и требует проверки.

Публикация сначала записывает неизменяемые части с хэшем в имени, затем атомарно
заменяет манифест и индекс. Предыдущие части сохраняются для читающих их клиентов.
Сборка приложения упаковывает только части текущего манифеста.

`usage prune` и `translate prune` проверяют все опубликованные колоды перед
очисткой общих TSV. Повреждённая или недоступная публикация отменяет операцию.
