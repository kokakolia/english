# Английские коллокации

Локальное PWA для интервального повторения английских коллокаций: предложение
с пропуском и переводом, раскрытие ответа, самопроверка и расписание FSRS.
Колода содержит 1008 карточек. Прогресс хранится в IndexedDB браузера.

Для запуска нужны Node.js 22.12+ и npm в PATH:

```powershell
cd app
npm ci
npm start
```

На Windows можно запускать `Коллокации.cmd`. Собранное приложение работает
на `http://localhost:5173`; разработка — на `http://localhost:5174`.
Это разные источники с разными базами: рабочий прогресс хранится на 5173.
После первой загрузки установленное PWA работает офлайн.

```powershell
cd app
npm test
npm run typecheck
npm run build
```

Python-пайплайн: `python -m pip install -r pipeline/requirements.txt`.
Проверки из корня:

```powershell
python -m pipeline.normalize.selftest
python -m pipeline.rank.selftest
python -m pipeline.deck.selftest
python -m unittest pipeline.deck.test_publication
```

Исходные статьи и SQLite находятся в игнорируемом `pipeline/data/`.
Для повторной генерации нужны скачанные статьи; готовая колода включена
в репозиторий и для запуска приложения этого достаточно.

- `app/src/srs` — планировщик, очередь, сессия.
- `app/src/storage` — база, импорт колод, резервные копии.
- `app/src/study` — контроллер занятия; `app/src/ui` — экраны.
- `pipeline` — источник ozdic, нормализация, ранжирование, сборка.
- `decks` — готовые колоды; `schema/card-identities.json` — постоянные ID.
- `translations`, `notes`, `sentences` — ручные переводы, пояснения и правки.

Копия из меню содержит карточки, прогресс, журнал и время изменений состояния.
Сохраняйте её перед переносом данных на другое устройство. Старые форматы 1 и 2
читаются новой версией; новые копии формата 3 требуют обновлённого приложения.
События повторений имеют постоянные ID: оценки в одну миллисекунду сохраняются
раздельно, а повторное слияние копии не дублирует их.
Разрешение на папку резервных копий выбирается отдельно на каждом устройстве.

Дневной лимит общий для всех занятий за местные сутки. Обновление колоды
сохраняет прогресс по ID. При изменении предложения или набора партнёров
пояснение требует повторной проверки независимо от сохранения ID.

Одновременно работает один экземпляр в одном профиле браузера. Повторный
запуск установленного PWA переключает на существующее окно в поддерживающих
браузерах. Дополнительная вкладка показывает «Приложение уже открыто» и не
открывает базу; после закрытия первого окна нажмите «Проверить снова».
Для этого нужен Web Locks API (поддерживается актуальными Chrome и Edge).

Enter и пробел на сфокусированной кнопке выполняют её действие. Сокращения
занятия действуют вне элементов управления, при закрытом меню, без модификаторов
и без автоповтора удерживаемой клавиши. Ошибки хранилища и подготовки занятия
показываются отдельно от пустой очереди, с возможностью повторить попытку.

Старая сборка приложения не заменяет восстановленную более новую колоду.
Новые публикации колод используют контрольные суммы и неизменяемые части;
оборванная публикация сохраняет доступность предыдущей версии. Обновление
приложения применяется на экране дня после окончания операций с данными.
Экран дня пересчитывает очередь в полночь и при возвращении в окно PWA.
