# Макеты интерфейса

Исходные HTML-макеты, по которым разрабатывался интерфейс. Это визуальные
референсы; самостоятельные страницы не входят в приложение и офлайн-кэш.

- `card-desktop.html` — светлая карточка на компьютере.
- `card-mobile.html` — светлая карточка на телефоне.
- `dark-card-desktop.html` — тёмная карточка.
- `dark-home-desktop.html` — тёмный экран начала дня.

Актуальная адаптивная вёрстка находится в `app/src/ui`. Проверять изменения
нужно в приложении: короткие окна, обе темы и уменьшенное движение.
