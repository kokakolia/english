# Сопровождение

## Проверки зависимостей

Из `app`:

```sh
npm audit
npm audit --omit=dev
```

Проверка от 29 октября 2026: предупреждения высокого и среднего уровня
исправлены совместимыми обновлениями lock-файла. В рабочих зависимостях
приложения предупреждений нет.

Остаются четыре предупреждения низкого уровня в цепочке
`vite-plugin-pwa → workbox-build → @rollup/plugin-node-resolve → deepmerge`.
Это инструменты сборки. Последняя опубликованная версия `deepmerge` — 4.3.1;
она затронута [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4).
После появления исправления обновить зависимости и проверить офлайн-обновление PWA.

Предложение `npm audit fix --force` откатывает PWA-плагин до 0.2.1.
Такой откат не применяется автоматически к проекту на Vite 8.

## После обновления инструментов

Выполнить команды из CONTRIBUTING.md. В отдельном профиле браузера проверить
первый запуск, работу без сети, сохранение и восстановление копии, а также
отложенное обновление во время занятия. Проверка в основном профиле может
затронуть личный прогресс.
