# Ядро интервального повторения

Чистая логика без React, сети и хранилища. Проверки запускаются из `app`:

```sh
npm test
npm run typecheck
```

| Файл           | Ответственность                                                |
| -------------- | -------------------------------------------------------------- |
| `types.ts`     | Карточка, прогресс, журнал и оценки                            |
| `scheduler.ts` | Обёртка над ts-fsrs и сериализация дат и состояний             |
| `queue.ts`     | Дневные лимиты, порядок карточек и разведение родственных слов |
| `session.ts`   | Текущая карточка, повторы внутри занятия и снимки для отмены   |

Содержимое карточки неизменно. Прогресс связывается с ней по постоянному ID,
а даты хранятся строками ISO. Изменение контента не должно стирать расписание.
Проверку ответа выполняет учащийся; автоматического сравнения словоформ в ядре нет.

Очередь получает уже израсходованные дневные лимиты от хранилища. Новые карточки
вплетаются между повторениями, карточки одного слова по возможности раздвигаются.
При невозможности выдержать интервал карточка остаётся в очереди. Недоученные
карточки с коротким сроком не отсекаются дневным лимитом обычных повторений.

Повторы выбираются по самым ранним срокам; перемешивание влияет только на
равные сроки. Если повторений больше оставшегося дневного лимита, новые
временно не добавляются. После разгрузки они возвращаются в обычную очередь.

Срок следующего показа определяет только FSRS. Контроллер сначала фиксирует
оценку в базе, затем передаёт сессии срок короткого повтора learning/relearning.
До этого срока показываются другие карточки, затем экран перерыва с ближайшим
временем. Таймер и возвращение в окно возобновляют занятие; повторное открытие
читает то же расписание из базы. Поля старых копий `againGap`, `repeatHard` и
`hardGap` принимаются для совместимости, но больше не меняют сроки.

Уже показанная карточка закреплена до оценки или действия: новый наступивший
повтор не подменит её во время ответа. Маркер отмены указывает на цепочку коротких
обратимых изменений, без копирования очереди и всех первых оценок на каждом шаге.
Размер истории растёт линейно с количеством действий. Отмена восстанавливает
очередь, активную карточку, счётчики и первые оценки вместе с расписанием в базе;
снимки чужого занятия или уже отменённой ветки отклоняются до изменения состояния.
Процент в итогах относится только к первым попыткам за это занятие;
`hard/good/easy` считаются вспоминанием, `again` — нет. Все оценки и количество
дополнительных попыток показываются отдельно.

Тесты охватывают переходы FSRS, лимиты и порядок очереди, восстановление снимков,
настоящую колоду и длительные симуляции занятий.
