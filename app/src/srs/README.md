# Ядро интервального повторения

Чистая логика без React, сети и хранилища. Проверки запускаются из `app`:

```sh
npm test
npm run typecheck
```

| Файл           | Ответственность                                                |
| -------------- | -------------------------------------------------------------- |
| `types.ts`     | Карточка, прогресс, журнал и оценки                            |
| `scheduler.ts` | Обёртка над ts-fsrs и сериализация дат и состояний             |
| `queue.ts`     | Дневные лимиты, порядок карточек и разведение родственных слов |
| `session.ts`   | Текущая карточка, повторы внутри занятия и снимки для отмены   |

Содержимое карточки неизменно. Прогресс связывается с ней по постоянному ID,
а даты хранятся строками ISO. Изменение контента не должно стирать расписание.
Проверку ответа выполняет учащийся; автоматического сравнения словоформ в ядре нет.

Очередь получает уже израсходованные дневные лимиты от хранилища. Новые карточки
вплетаются между повторениями, карточки одного слова по возможности раздвигаются.
При невозможности выдержать интервал карточка остаётся в очереди. Недоученные
карточки с коротким сроком не отсекаются дневным лимитом обычных повторений.

Сессия возвращает «Не знал» через `againGap` карточек и, при `repeatHard`,
«Плохо помню» через `hardGap`. Она не обращается к FSRS и не сохраняет данные.
Контроллер сначала фиксирует оценку в базе, затем изменяет очередь сессии.
Снимок содержит очередь и счётчики; он позволяет отменить шаг без обратного
пересчёта расписания FSRS.

Тесты охватывают переходы FSRS, лимиты и порядок очереди, восстановление снимков,
настоящую колоду и длительные симуляции занятий.
