# Приложение

Офлайн-PWA на React и TypeScript. Занятие состоит из самостоятельного
вспоминания, раскрытия карточки и одной из четырёх оценок.

## Команды

```sh
npm ci
npm run dev           # разработка: 5174
npm start             # сборка и открытие рабочей версии: 5173
npm run check         # формат, типы, тесты приложения и скриптов
npm run build         # dist + service worker
npm run preview       # просмотр готовой сборки: 5173
npm run format
```

Порты закреплены: при занятом порте запуск останавливается. Разработка и рабочая
версия используют разные хранилища, чтобы проверка кода не меняла реальный прогресс.

## Архитектура

| Слой                                   | Ответственность                                                  |
| -------------------------------------- | ---------------------------------------------------------------- |
| [`src/srs`](src/srs/README.md)         | FSRS, очередь дня, родственные карточки и повторы внутри занятия |
| [`src/storage`](src/storage/README.md) | Dexie, импорт колод, атомарная запись ответа и копии             |
| `src/study/controller.ts`              | Состояние занятия, оценки, действия над карточкой и отмена       |
| `src/app`                              | Запуск, один экземпляр, тема, сохранность данных и обновление    |
| `src/ui`                               | Экраны и события React; подписка на контроллер                   |
| `src/assets/fonts`                     | Локальные шрифты, включаемые Vite в сборку                       |
| `scripts`                              | Подготовка колод, иконок и шрифтов                               |

Контроллер не зависит от React. Планировщик не зависит от браузера и базы.
Интерфейс показывает состояние контроллера и передаёт ему действия пользователя.
Автоматического распознавания введённого ответа нет.

## Очередь и запись ответа

Суточные лимиты общие для всех занятий. Карточки одного слова по возможности
разнесены; новые карточки распределяются между повторениями.

| Оценка        | Повтор в текущем занятии по умолчанию |
| ------------- | ------------------------------------- |
| Не знал       | Через 3 карточки                      |
| Плохо помню   | Через 6 карточек                      |
| Помню         | Завершена                             |
| Отлично помню | Завершена                             |

FSRS отдельно определяет срок следующего занятия. Прогресс, журнал и отметка
изменения пишутся одной транзакцией **до** перехода к следующей карточке.
Отмена возвращает расписание и очередь, сохраняя событие с пометкой отмены.

## Хранилище и восстановление

Контент и прогресс разделены. Старая сборка не понижает восстановленную более
новую колоду. Конфликт владельцев одного ID отклоняется внутри транзакции.
События журнала имеют постоянные ID, поэтому повторное слияние копии не создаёт дублей.

`BackupRestore` используется в меню и на экране ошибки запуска. Общая блокировка
не позволяет начать занятие во время чтения, слияния и перечитывания копии.
Неверный файл освобождает блокировку и позволяет повторить попытку.

`InstanceGate` получает Web Lock до открытия базы. Повторное окно показывает
сообщение об уже работающем экземпляре. `launch_handler` возвращает
установленное PWA в существующее окно в поддерживающих браузерах.

## Офлайн и обновления

`scripts/sync-decks.mjs` копирует только файлы из текущих манифестов.
Невостребованные части исходных публикаций не попадают в `public` и офлайн-кэш.
Проверка полноты происходит до очистки предыдущей public-копии.

Service worker кэширует приложение и колоду. Новая версия перезагружает страницу
на экране дня после окончания всех операций с данными. Занятие не прерывается.
Экран дня обновляет сроки в полночь, раз в минуту и при возвращении в окно PWA.

## Оформление

Две темы используют ролевые CSS-переменные в `src/ui/styles.css`. Системная тема
следит за изменениями ОС. При нехватке высоты прокручивается содержимое карточки;
кнопки оценки остаются доступными. Учитывается настройка уменьшенного движения ОС.

Макеты — в [`docs/design`](../docs/design/README.md). Шрифты локальные:
Marcellus для латинских заголовков, Cormorant Garamond для кириллицы, Lora для текста.
Иконки обновляются через `npm run icons`, шрифты — `node scripts/fetch-fonts.mjs`.

Редактирования карточек, полноценной статистики и экрана настроек занятий пока нет.
